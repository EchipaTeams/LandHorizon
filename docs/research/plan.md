# Research plan

Owned by the research coordinator. Brief: [coordinator-prompt.md](coordinator-prompt.md). Limits: [constraints.md](constraints.md). File format: [README.md](README.md).

Status values: `todo` → `researching` → `researched` (findings file written) → `reviewing` → `reviewed` (a `## Review` section is appended). Only `reviewed` files feed a synthesis, and only their `verified` claims.

## Rounds
- **Round 1 (small: usage nearly exhausted):** F1, then F3. Each gets a `researcher`, then a fresh `research-reviewer`. No synthesis.
- **Round 2 (only when the lead says usage has reset):** the rest, 3–5 researchers at a time, flood first. Then one follow-up round for gaps the reviews expose, then the syntheses and `RECOMMENDATIONS.md`.
